Safe for:
  ✓ Internal network
  ✓ Behind firewall/VPN
  ✓ Trusted network
  ✓ Dev/staging environment

NOT safe for:

🆘 TROUBLESHOOTING:

Can't connect from browser?
  → sudo ufw allow 8080/tcp
  → sudo ufw allow 8443/tcp

Service won't start?
  → docker compose logs
  → Check Docker: sudo systemctl status docker

Port already in use?
  → sudo lsof -i :8080
  → sudo kill -9 <PID>

Full troubleshooting: QUICK-DEPLOY.md § Troubleshooting
